# RogueLite Storage EXPANDED#

## About ##
RogueLite Storage adds a progression solution for hardcore packs/playing.
~~This mod adds a safe which has 9 slots, but it's no regular safe.~~
The safe features 27 slots (same size as a regular chest) and has a pretty cheap crafting recipe.
(I also fixed a bug that let you access the safe even when it's closed)

It's contents will persist between worlds meaning you get chose what you want to save for a future world.

_future update ideas_
- remake with multiple safe tiers (iron, diamond, netherite) with different storage sizes and independent inventories 

NOTE: 
ONLY FOR SINGLEPLAYER WORLDS. USING MULTIPLE SAFES WILL ONLY SAVE THE INVENTORY OF THE MOST RECENTLY USED SAFE, SO ONLY USE ONE PER WORLD.
